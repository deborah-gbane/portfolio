# Portfolio — Aïcha Déborah Gbane

Portfolio data science & intelligence artificielle (FR / EN).

- **Stack :** React 18, Vite, Three.js, GSAP, Lenis
- **Contenu :** `src/data.js` (projets, parcours, compétences) et `src/i18n.jsx` (textes de l'interface)
- **Animations 3D :** `src/components/DataHelix3D.jsx` · réseau de fond : `src/components/NeuroBackground.jsx`

## Lancer en local

```bash
npm install
npm run dev
```

## Déploiement

Chaque `git push` sur `main` reconstruit et publie le site sur GitHub Pages (`.github/workflows/deploy.yml`).
